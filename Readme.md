# PostApp 🚀

PostApp is a full-stack web application where users can create and explore posts with secure authentication and smooth routing functionality.

## Features ✨

- User authentication using JWT
- Login and signup system
- Protected routes
- Create and view posts
- Responsive user interface
- MVC project structure
- Secure backend integration

## Tech Stack 🛠️

- Node.js
- Express.js
- MongoDB
- EJS
- JWT Authentication

## Run Locally ⚡

```bash
npm install
npm start
